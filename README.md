# Tableau Retail & Sales Dashboard Project

 
## Overview

This project was completed as part of a **Data Technician Bootcamp** and demonstrates the use of **Tableau** to transform retail and sales data into interactive, business-focused dashboards. The project focused on analysing sales performance, identifying trends, and communicating insights through effective data storytelling and visualisation techniques.

 
## Objectives

- Explore and analyse retail and sales datasets.

- Create interactive dashboards for business decision-making.

- Visualise key performance indicators and sales trends.
  
- Apply data storytelling principles to communicate insights clearly.
  
 
## Skills Demonstrated

 
### Data Visualisation

Created a variety of chart types to present data from different perspectives, including:

- Bar Charts
  
- Line Charts

- Pie Charts
  
- Geographic Maps
  
- Comparative and trend analysis visualisations
  
 
### Interactive Dashboard Design

Developed user-friendly dashboards featuring:

- Interactive filters

- Slicers and parameter controls
  
- Drill-down functionality
  
- Dynamic dashboard interactions
  
- Custom navigation and user exploration features
  

### Tableau Features

Applied key Tableau capabilities such as:

- Calculated Fields for custom metrics and KPIs

- Data filtering and segmentation
  
- Sorting and ranking measures
  
- Aggregations and trend analysis
  
- Dashboard actions and interactivity
  
 
### Data Storytelling

Used data storytelling techniques to:

- Highlight sales performance trends

- Compare product and regional performance
  
- Identify high-performing and underperforming categories
  
- Present insights in a clear and visually engaging format
  
- Support data-driven decision making
  
 
## Key Insights

The dashboards enabled exploration of:

- Sales performance by region

- Product category trends
  
- Revenue growth over time
  
- Customer and market distribution
  
- Geographic sales patterns
  
  
## Tools Used

- Tableau Public

- Microsoft Excel / CSV Data Sources
  
- Data Cleaning and Preparation Techniques
  
- Business Intelligence and Data Visualisation Best Practices
  
 
## Outcome

This project strengthened my ability to create professional Tableau dashboards, build interactive visualisations, and transform raw retail and sales data into meaningful business insights. It demonstrates practical experience in data analysis, dashboard development and communicating findings through effective visual storytelling.
